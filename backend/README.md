# Biometric Attendance Platform — Backend

FastAPI backend for biometric attendance, with ZKTeco support and a self-contained demo profile for Render.

## Run the demo without MySQL or Redis

The demo profile is enabled with:

```env
MOCK_MODE=True
CORS_ORIGINS=https://your-site.netlify.app
```

When `MOCK_MODE=True`:

- MySQL repositories are replaced with in-memory repositories.
- Three demo devices are loaded automatically: Entry, Cafeteria and Exit.
- Full snapshots, new employees and Rush Hour attendance bursts are generated by the mock adapter.
- Manual synchronization and `sync-all` run directly without Celery or Redis.
- REST and the in-memory WebSocket endpoint work in one Render web service.
- Data is temporary and is lost when the Render instance restarts or redeploys.

`DATABASE_URL` and `REDIS_URL` are **not required for this demo profile**.

## Production profile

Set `MOCK_MODE=False` to use MySQL repositories and physical ZKTeco devices. The production profile requires:

```env
DATABASE_URL=mysql+pymysql://user:password@host:3306/attendance
REDIS_URL=redis://user:password@host:6379/0
CORS_ORIGINS=https://your-site.netlify.app
```

Celery Worker and Beat process synchronization jobs and full snapshots every five minutes. Alembic owns schema migrations. `network_mode: host` is required when the backend runs in the same LAN as physical devices; this is not available on Render, so Render deployments must use `MOCK_MODE=True`.

## Local setup

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
$env:MOCK_MODE = "True"
$env:CORS_ORIGINS = "http://localhost:5173"
uvicorn src.main:app --reload
```

API endpoints:

- `GET /health`
- `GET /docs`
- `GET /devices`
- `POST /devices/{device_id}/sync`
- `POST /devices/sync-all`
- `WS /ws/devices`

## Backend layout

```text
src/domain/          Entities and business concepts
src/application/     Use cases and ports
src/infrastructure/  FastAPI, adapters, repositories and queues
alembic/              Database migrations for the production profile
```

`BiometricDeviceRepository` is the application port. `ZKTecoBiometricDeviceRepository` is the only adapter that imports `pyzk`; `MockFingerprintDevice` implements the same contract for demo and tests.
